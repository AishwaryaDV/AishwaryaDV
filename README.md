## Things I've built

- **[Reddit Outreach](https://github.com/AishwaryaDV/reddit-outreach)** — LLM outreach pipeline with model routing, guardrails, and a golden-set eval harness, behind human approval. FastAPI, React, PostgreSQL.
- **[Offroute](https://github.com/AishwaryaDV/Offroute)** — self-hosted travel PWA with shareable, clonable map circuits and Astra, a multi-model AI assistant with an audit trail. Next.js, MapLibre GL, FastAPI, PostGIS.
- **[SimuFlow](https://github.com/AishwaryaDV/Simuflow)** — distributed systems simulator with a Web Worker tick engine, chaos-engineering fault injection, and p50/p99 and cost metrics. React, ReactFlow, MobX.
- **[TripLedger](https://github.com/AishwaryaDV/Tripledger)** — multi-currency group expense splitter with debt minimization, an AI assistant, and a multimodal receipt scanner. React, MobX, FastAPI, Supabase.
- **[Safe-DB-MCP](https://github.com/AishwaryaDV/safe-db-mcp)** — a read-only database MCP server (SQLite in v1, with Postgres/MySQL as the next scope) that validates every model-written query through a sqlglot allow-list, SQLite authorizer, timeout, and row caps, logs all calls (including blocked ones) to an audit table, and ships a Spider-benchmark harness that measures a model's text-to-SQL execution accuracy through the live MCP interface. FastAPI, Next.js, SQLite, MCP Python SDK, sqlglot, pytest.

Work has included a real-time platform for 4,000+ smart devices at Orion Sleep (MQTT with tiered QoS, a ClickHouse and Grafana telemetry pipeline, ~82% lower query latency), a global trade-filtering platform on microservices at BT Group, high-traffic e-commerce at Publicis Sapient, and SoulTalk, an AI journaling app with a RAG pipeline, live on the App Store, where I built the React Native frontend.
